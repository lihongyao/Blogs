# 概述

当前负责项目基于 [next-intl](https://next-intl.dev/) 国际化 + [Next.js 16 App Router](https://nextjs.org/docs) 实现，业务上有一个需求是要实现 **路由弹窗**，也就是弹窗的打开与关闭完全由 URL 控制，并且支持刷新后仍然保持弹窗状态以及浏览器前进后退。

官方推荐的 Intercepting Routes + Parallel Routes 方案在刷新后会退化为独立页面渲染，无法继续以 **弹窗形式** 展示，因此不满足需求。调研后发现，可以通过 **Rewrite** 的方式实现这一能力。

大致思路如下：

- URL 设计：在当前 pathname 末尾追加一个 modal 段。例如 `/` → `/modal-login`，或 `/en/details/1` → `/en/details/1/modal-login`。关闭时通过 `router.back()` 或使用 `router.replace` 移除最后一段实现。
- 服务端处理：当请求携带 modal 段时，在进入 App 前做一次 rewrite，让请求实际匹配到 **带 locale 的基础路径**。这样 `[locale]` layout 的 params.locale 能正确解析，next-intl 正常工作。同时浏览器地址栏保持完整 URL，供前端解析。
- 前端渲染：在 `[locale]` layout 中挂载 RouteModalRenderer。通过 pathname 解析出在 ModalComponents 中注册的 modal 段，按顺序渲染对应组件，并统一处理关闭逻辑和 body 滚动。退出动画通过 AnimatePresence 控制，在 onExitComplete 后再卸载，避免闪烁。

弹窗组件统一放在 `app/[locale]/(modals)/` 目录下。其中 `(modals)` 是 **路由组**，不会出现在 URL 中，仅用于组织结构。

在 `libs/routes.ts` 中定义所有 modal 路径常量

在 `(modals)/index.ts` 中完成「段名 → 组件」的映射，并通过 dynamic 方式引入。

RouteModalRenderer 不直接依赖具体组件，只根据当前 pathname 解析出的段名，以及这份映射表进行渲染。

## 2️⃣ 定义 Modal 路径与组件映射

这一层的目标很简单：**统一管理路由常量，并建立 “路径段 → 组件” 的映射关系**。

在 src/libs/routes.ts 中统一定义页面路由和弹窗路由：

```ts

export const PageRoutes = {
```

## 3️⃣ proxy 中处理带 modal 的完整路径

```ts
// src/proxy.ts
import createMiddleware from 'next-intl/middleware';
import { type NextRequest, NextResponse } from 'next/server';

import { routing } from './i18n/routing';
import { ModalRoute, ModalRoutes } from './libs/routes';

const intlMiddleware = createMiddleware(routing);

const modalRouteValues = new Set(Object.values(ModalRoutes));
const defaultLocale = routing.defaultLocale;
const locales = routing.locales;

// 处理国际化路由和 modal 路由重写
export function proxy(request: NextRequest) {
  const rewriteTarget = modalRewriteUrl(request);
  if (rewriteTarget) {
    // Next.js 16 用 NextResponse.rewrite() 做重写，不再使用 x-middleware-rewrite header
    return NextResponse.rewrite(rewriteTarget);
  }
  return intlMiddleware(request);
}

function modalRewriteUrl(request: NextRequest) {
  const { pathname, searchParams } = request.nextUrl;

  // modal 路由判断：是否命中 ModalRoutes
  const modalRouteKey = matchModalRoute(pathname);
  if (!modalRouteKey) return null;

  const pathnames = pathname.split('/').filter(Boolean);
  const modalIndex = pathnames.findIndex((segment) => `/${segment}` == modalRouteKey);
  if (modalIndex === -1) return null;

  const basePaths = pathnames.slice(0, modalIndex);

  // 检查路径是否包含语言前缀，则加上默认语言
  const hasLocalePrefix = basePaths.length > 0 && locales.includes(basePaths[0]);
  if (!hasLocalePrefix) {
    basePaths.unshift(defaultLocale);
  }

  const basePath = `/${basePaths.join('/')}`;

  // 克隆请求的URL对象，在其基础上修改
  const rewriteUrl = request.nextUrl.clone();
  // 设置基础路径，确保没有多余的斜杠
  rewriteUrl.pathname = basePath.replace(/\/{2,}/g, '/');

  const nextParams = new URLSearchParams(searchParams.toString());
  // 将查询参数赋值给 URL
  rewriteUrl.search = nextParams.toString() ? `?${nextParams.toString()}` : '';
  // 返回新的 URL（Next.js 会用它来执行 rewrite）
  return rewriteUrl;
}

function matchModalRoute(pathname: string) {
  const segments = pathname.split('/').filter(Boolean);
  if (segments.length == 0) return null;
  // 遍历路径段，找到是否有段匹配 ModalRoutes 的值（忽略前导斜杠差异）
  for (let i = 0; i < segments.length; i++) {
    const seg = `/${segments[i]}`;
    if (modalRouteValues.has(seg as ModalRoute)) return seg;
  }
  return null;
}

export const config = {
  // Match all pathnames except for
  // - … if they start with `/api`, `/trpc`, `/_next` or `/_vercel`
  // - … the ones containing a dot (e.g. `favicon.ico`)
  matcher: '/((?!api|trpc|_next|_vercel|.*\\..*).*)',
};

```

## 4️⃣ next.config.ts 配置

在路由匹配前，把「仅含 modal 路径」的请求重写到默认语言路径，避免 App Router 把 `modal-xxx` 等误当成 `[locale]`。

```ts
// src/next.config.ts
import type { NextConfig } from 'next';
import createNextIntlPlugin from 'next-intl/plugin';

import brandConfig from './src/configs/brands';
import { ModalRoutes } from './src/libs/routes';

const defaultLocale = brandConfig.defaultLocale;
const modalRewrites = (Object.values(ModalRoutes) as string[]).map((path) => ({
  source: path,
  destination: `/${defaultLocale}`,
}));

const nextConfig: NextConfig = {
  /* config options here */
  reactCompiler: true,
  reactStrictMode: false,
  // 在路由匹配前把 /modal-xxx 等重写到 /{defaultLocale}，避免被 [locale] 误匹配成 locale
  rewrites: async () => ({
    beforeFiles: modalRewrites,
  }),
};
const withNextIntl = createNextIntlPlugin();
export default withNextIntl(nextConfig);
```

当用户直接访问 `/modal-login` 时，先被重写到 `/{defaultLocale}`，请求以「有 locale 的路径」进入 app，`[locale]` 不会拿到非法 locale。

## 6️⃣ RouteModalRenderer 与 useSwipeBack

### RouteModalRenderer

- 从 pathname 解析段：`pathSegments.filter((s) => ModalComponents[s])` 得到 `modalKeys`，再得到组件列表。
- 关闭：优先 `router.back()`，否则从 path 去掉最后一段做 `router.replace`。
- 用 `AnimatePresence` 包住列表；路由变空时先不 return null，等 `onExitComplete` 再设 `pureHidden` 并 return null，这样退出动画能播完。
- 弹窗统一接收 `onCloseAction`，由 `RouteModalRenderer` 传入。

> `usePathname`、`useRouter` 建议来自 `@/i18n/navigation`，保证与 next-intl 一致。若项目已统一使用 `next/navigation`，也可直接使用。

```tsx
// src/components/features/RouteModalRenderer.tsx
'use client';

import { useCallback, useEffect, useMemo, useState } from 'react';

import { usePathname, useRouter, useSearchParams } from 'next/navigation';

import { AnimatePresence, motion } from 'framer-motion';

import {
  modalBackdropVariantsDesktop,
  modalBackdropVariantsMobile,
  modalContentVariantsDesktop,
  modalContentVariantsMobile,
} from '@/animations/modal-animations';
import { ModalComponents } from '@/app/[locale]/(modals)';
import { useDevice } from '@/hooks/useDevices';
import { useSwipeBack } from '@/hooks/useSwipeBack';
import { routing } from '@/i18n/routing';

export type ModalComponentProps = {
  onClose: () => void;
};

/**
 * 根据 URL 中的 modal 段（如 /en/modal-login）渲染对应弹窗，支持多层级叠加。
 * 进入从右往左滑，关闭时由 AnimatePresence 播完 exit 再卸载。
 */
export default function RouteModalRenderer() {
  const router = useRouter();
  const pathname = usePathname();
  const pathSegments = pathname.split('/').filter(Boolean);
  const searchParams = useSearchParams();
  const searchParamsString = searchParams.toString();

  const [isAllow, setIsAllow] = useState(true);
  // 路由里没 modal 时先不拆 AnimatePresence，等 exit 播完再隐藏，否则关的时候会闪没
  const [pureHidden, setPureHidden] = useState(false);

  const modalKeys = useMemo(() => pathSegments.filter((s) => ModalComponents[s]), [pathSegments]);
  const ModalComponent = useMemo(
    () => modalKeys.filter(Boolean).map((m) => ModalComponents[m]),
    [modalKeys],
  );

  const onClose = useCallback(() => {
    if (ModalComponent.length <= 0) return;

    const canGoBack = window.history.length > 2;
    if (canGoBack) {
      router.back();
      return;
    }

    const params = new URLSearchParams(searchParamsString);
    const nextQuery = params.toString();
    const newPathSegments = [...pathSegments];
    newPathSegments.pop();
    const nextPath = `/${newPathSegments.join('/')}`;
    const finalPath = nextPath || `/${routing.defaultLocale}`;
    const nextUrl = nextQuery ? `${finalPath}?${nextQuery}` : finalPath;
    router.replace(nextUrl, { scroll: false });
  }, [ModalComponent, router, pathSegments, searchParams]);

  const { isMobile } = useDevice();
  useSwipeBack((value) => setIsAllow(!value), { enabled: ModalComponent.length > 0 });

  useEffect(() => {
    if (ModalComponent.length) {
      setPureHidden(false);
      document.body.style.overflow = 'hidden';
      document.documentElement.style.overflow = 'hidden';
    } else {
      setIsAllow(true);
      document.body.style.overflow = '';
      document.documentElement.style.overflow = '';
    }
  }, [ModalComponent.length]);

  if (pureHidden) return null;

  return (
    <AnimatePresence
      onExitComplete={() => {
        if (ModalComponent.length <= 0) setPureHidden(true);
      }}
    >
      {ModalComponent.map((Modal, idx) => {
        const modalKey = modalKeys[idx];
        return (
          <motion.div
            key={modalKey}
            data-name={`modal-${modalKey}`}
            className="fixed inset-0 z-auto flex items-center justify-center"
          >
            <motion.div
              className="absolute size-full bg-black/70"
              variants={
                isAllow
                  ? isMobile
                    ? modalBackdropVariantsMobile
                    : modalBackdropVariantsDesktop
                  : undefined
              }
              initial="hidden"
              animate="visible"
              exit="exit"
              onClick={() => {
                console.log('onMaskClick');
              }}
            />
            <motion.div
              variants={
                isAllow
                  ? isMobile
                    ? modalContentVariantsMobile
                    : modalContentVariantsDesktop
                  : undefined
              }
              initial="hidden"
              animate="visible"
              exit="exit"
              style={{ willChange: 'transform, opacity' }}
            >
              <Modal onClose={onClose} />
            </motion.div>
          </motion.div>
        );
      })}
    </AnimatePresence>
  );
}

```

### useSwipeBack（可选）

左边缘滑动时禁用进入/退出动画，避免与手势冲突：

```ts
// src/hooks/useSwipeBack.ts
'use client';
import { useEffect } from 'react';

type SwipeBackOptions = {
  enabled?: boolean;
  edge?: number; // 左边缘阈值
  distance?: number; // 触发距离
};

export function useSwipeBack(onSwipe: (value: boolean) => void, options: SwipeBackOptions = {}) {
  const { enabled = true, edge = 30, distance = 50 } = options;

  useEffect(() => {
    if (!enabled) return;
    let startX = 0;
    let startY = 0;
    let swiped = false;

    const onTouchStart = (e: TouchEvent) => {
      const t = e.touches[0];
      startX = t.clientX;
      startY = t.clientY;
      swiped = false;
    };

    const onTouchMove = (e: TouchEvent) => {
      const t = e.touches[0];
      const dx = Math.abs(t.clientX - startX);
      const dy = Math.abs(t.clientY - startY);

      if (startX < edge && dx > distance && dx > dy) {
        swiped = true;
      }
    };

    const onTouchEnd = () => {
      onSwipe(swiped);
    };

    window.addEventListener('touchstart', onTouchStart, { passive: true });
    window.addEventListener('touchmove', onTouchMove, { passive: true });
    window.addEventListener('touchend', onTouchEnd);

    return () => {
      window.removeEventListener('touchstart', onTouchStart);
      window.removeEventListener('touchmove', onTouchMove);
      window.removeEventListener('touchend', onTouchEnd);
    };
  }, [enabled, onSwipe, edge, distance]);
}

```

## 7️⃣ useModalRoutes：打开弹窗的 path 计算

```ts
// src/hooks/useModalRoutes.ts
import { usePathname } from '@/i18n/navigation';

export const useModalRoutes = () => {
  const pathname = usePathname();

  const getMergePath = (target: string) => {
    if (!target) return target;
    // 确保目标路由以斜杠开头
    target = target.startsWith('/') ? target : `/${target}`;
    const base = pathname.endsWith('/') ? pathname.slice(0, -1) : pathname;
    const index = pathname.indexOf(target);
    return index !== -1 ? `${pathname.slice(0, index)}${target}` : `${base}${target}`;
  };

  return {
    getMergePath,
  };
};
```

## 8️⃣ 在 layout 中挂载

在 `app/[locale]/layout.tsx` 中与 `children` 并列挂载 `RouteModalRenderer`：

```tsx
// src/app/[locale]/layout.tsx（仅展示与路由弹窗相关的部分）
import { NextIntlClientProvider, hasLocale } from 'next-intl';
import { getMessages, setRequestLocale } from 'next-intl/server';
import { notFound } from 'next/navigation';

import RouteModalRenderer from '@/components/features/RouteModalRenderer';
import { routing } from '@/i18n/routing';

export default async function LocaleLayout({
  children,
  params,
}: Readonly<{
  children: React.ReactNode;
  params: { locale: string };
}>) {
  const { locale } = await params;

  if (!hasLocale(routing.locales, locale)) {
    notFound();
  }

  setRequestLocale(locale);
  const messages = await getMessages();

  return (
    <html lang={locale}>
      <body>
        <NextIntlClientProvider messages={messages} locale={locale}>
          {children}
          <RouteModalRenderer />
        </NextIntlClientProvider>
      </body>
    </html>
  );
}
```

## 9️⃣ 打开与关闭弹窗

### 打开

用 `useModalRoutes().getMergePath(ModalRoute)` 得到「当前 path + modal 段」，再用 `router.push` 或 `Link`：

```tsx
// 示例：在任意页面打开登录弹窗
'use client';

import { useRouter } from '@/i18n/navigation';
import { useModalRoutes } from '@/hooks/useModalRoutes';
import { ModalRoutes } from '@/libs/routes';

export default function HomePage() {
  const router = useRouter();
  const { getMergePath } = useModalRoutes();

  const openLogin = () => {
    const path = getMergePath(ModalRoutes.ModalLogin);
    router.push(path, { scroll: false });
  };

  return (
    <div>
      <button onClick={openLogin}>打开登录弹窗</button>
    </div>
  );
}
```

或用 `Link`：

```tsx
import { Link } from '@/i18n/navigation';
import { useModalRoutes } from '@/hooks/useModalRoutes';
import { ModalRoutes } from '@/libs/routes';

export default function HomePage() {
  const { getMergePath } = useModalRoutes();

  return (
    <Link href={getMergePath(ModalRoutes.ModalLogin)} scroll={false}>
      打开登录弹窗
    </Link>
  );
}
```

### 关闭

弹窗内调用 `onCloseAction()`，由 `RouteModalRenderer` 内部执行 `router.back()` 或 `router.replace`。

# 注意事项

- **pathname 来源**

  所有读取 pathname、执行跳转的地方，统一使用 @/i18n/navigation 中封装的 usePathname / useRouter，不要直接使用 next/navigation。否则会出现 locale 前缀不一致的问题。

- **next.config 的 rewrites**

  beforeFiles 只负责处理「纯 modal 路径」到默认 locale 的映射。

  带 locale 的路径（例如 /en/modal-login）不在这里处理，而是交由 proxy 进行 rewrite。

- **proxy 与 middleware 执行顺序**

  必须先执行 modal 的 rewrite，再进入 next-intl 的 middleware。

  这样带 modal 的请求才能以「base 路径 + 正确 locale」的形式进入 App，保证国际化上下文正常。

- **退出动画**

  当路由变为空时，不要立即 return null。

  应在 onExitComplete 回调触发，并且确认当前没有 modal 后，再设置 pureHidden 并返回 null。否则 exit 动画会来不及播放，出现“闪没”的问题。

- **新增弹窗**

  只需在 ModalRoutes 和 ModalComponents 中各新增一项，并确保 proxy 与 next.config 中使用的 ModalRoutes 保持一致即可。

  不需要改动渲染逻辑。
